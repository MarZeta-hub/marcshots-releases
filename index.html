Instalar

  1. Abre esta página desde el móvil y pulsa Descargar APK.
  2. La primera vez, Android te pedirá permiso para instalar aplicaciones desconocidas desde el navegador. Acéptalo.
  3. Para actualizar, instala la nueva versión encima. No se pierden los datos.
  4. Desde la app: toca el título → Aplicación → Comprobar actualizaciones.

Qué hace

  • Lista de partidos del día, con filtros por estado y búsqueda
  • Detalle del partido: marcador, incidencias y tiros
  • Últimos eventos de cada partido, con filtros y retraso anti-spoilers
  • Partidos marcados que siguen visibles en la lista de hoy
